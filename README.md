# OpenTube

Десктопное приложение для загрузки видео и аудио с YouTube.

## Возможности

- Загрузка видео в различном качестве (от 144p до 4K+)
- Извлечение аудиодорожки в формате MP3 (192 kbps)
- Автоматическое определение доступных форматов
- Предпросмотр превью и метаданных (название, канал, длительность)
- Прогресс-бар загрузки со скоростью и оставшимся временем
- История загрузок с возможностью открыть файл
- Выбор папки сохранения
- Современный тёмный интерфейс

## Установка

### Требования

- Python 3.10+
- FFmpeg (для конвертации аудио в MP3 и объединения видео+аудио)

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Установка FFmpeg

- **Windows**: скачайте с [ffmpeg.org](https://ffmpeg.org/download.html) и добавьте в PATH
- **macOS**: `brew install ffmpeg`
- **Linux**: `sudo apt install ffmpeg`

## Запуск

```bash
python main.py
```

## Использование

1. Вставьте ссылку на YouTube видео в поле ввода
2. Нажмите «Получить информацию»
3. Выберите качество из выпадающего списка или отметьте «Только аудио»
4. Выберите папку сохранения (по умолчанию `~/Downloads/OpenTube`)
5. Нажмите «Скачать»

## Технологии

- **PyQt6** — GUI фреймворк
- **yt-dlp** — движок загрузки с YouTube
- **FFmpeg** — обработка медиа (конвертация, объединение)
